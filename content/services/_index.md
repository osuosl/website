## [Hosting Services](/services/hosting/)

The OSL provides [hosting services](/services/hosting/) for more than 300 leading open source
[communities](/projects), including Debian, Fedora, Gentoo, GNOME and Drupal.

We understand that every open source project has different hosting needs. We work with each project we host to meet
those needs and to create an infrastructure that will grow along with the project.
[Read more about our hosting services](/services/hosting).

## [POWER Development Hosting](/services/powerdev)

The OSL partners with [IBM](https://www.ibm.com/power) to host POWER-based servers, making POWER9 and POWER10 virtual
machines available to the open source community through our OpenStack cluster. We also run POWER CI, a Jenkins service
for building and testing projects on POWER. These systems are intended for functional development, testing and
continuous integration, but are not to be used for performance testing.
[Read more about our POWER development hosting services](/services/powerdev)

## [AARCH64 Development Hosting](/services/aarch64)

The OSL partners with [Ampere Computing](https://amperecomputing.com/) to host
[AARCH64](https://en.wikipedia.org/wiki/ARM_architecture#AArch64)-based servers, making AARCH64-based KVM guests
available to the open source community. Community members can use these AARCH64 servers to develop and test open source
projects on the AARCH64 architecture. These systems are intended for functional development and testing work, but are
not to be used for performance testing. [Read more about our AARCH64 hosting services](/services/aarch64).

## [IBM Z Development Hosting](/services/ibm-z)

The OSL partners with [Marist University](https://www.marist.edu/) to provide access to IBM Z-based servers through
IBM Z CI, a Jenkins service that lets open source projects build and test on the s390x architecture.
[Read more about our IBM Z CI service](/services/ibm-z)
